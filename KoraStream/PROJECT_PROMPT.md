# KoraStream — Complete Android App-Like Live Match & Sports Streaming Platform

> This document is a comprehensive project blueprint that describes the KoraStream platform. It is designed to act as a prompt for building, modifying, or extending the project from scratch. The website's frontend is specifically designed to look, feel, and behave like a native Android Mobile Application (Material Design 3, Mobile-First, PWA-Ready) while maintaining a clean responsive dashboard on the admin side. All paths are relative to the project root (`kora-stream/`).

---

## 1. Project Overview

**Name:** KoraStream  
**Type:** Mobile-First Live Football/Sports Match Streaming Web App (Android App Layout) & Admin Dashboard  
**Purpose:** A sports streaming portal where the client frontend is designed like a native Android App, featuring a bottom navigation bar, top app bar, sliding date tabs, bottom sheets for stream server selection, and PWA (Progressive Web App) capabilities. It includes a complete Admin Dashboard for backend management.  
**Built with:** PHP (vanilla, no framework), MySQL, HTML, Tailwind CSS, JavaScript (vanilla)  
**Architecture:** Custom MVC-like pattern (Controllers, Models, Views, Routes)  
**Font:** Outfit & Inter (Google Fonts) — weights 300, 400, 500, 600, 700, 800  
**Icon Library:** Font Awesome 6.5.1 (CDN) or Google Material Icons  
**PWA Support:** `manifest.json` and a service worker to enable "Add to Home Screen" on Android devices, hiding the browser address bar.  
**Authentication:** Session-based admin login with bcrypt password hashing

## 3. Design System & Android Native Interface Guidelines

### Theme: Mobile-First Material You (Dark Mode / Sports Neon)

The frontend adopts a **mobile-app layout structure** (best viewed on mobile width, centered with a maximum width of `max-w-md` on desktop screens to preserve the look and feel of an Android app).

#### Mobile Shell Configuration
- **Viewport Safe-Areas:** Formatted with `padding-top: env(safe-area-inset-top)` and `padding-bottom: env(safe-area-inset-bottom)` to run flawlessly in full-screen on modern smartphones.
- **Scroll Behavior:** Smooth native-style scrolling with hidden scrollbars for horizontal categories:
  ```css
  .no-scrollbar::-webkit-scrollbar { display: none; }
  .no-scrollbar { -ms-overflow-style: none; scrollbar-width: none; }
  ```

#### Color Palette (Tailwind Configurations)
- **StatusBar & AppBar Background:** Deep Onyx Black (`bg-[#090D16]`)
- **App Canvas (Body Background):** Dark Slate Gray (`bg-[#0F1322]`)
- **App Cards & Navigation Surfaces:** Card Surface (`bg-[#181E31]`) with rounded-2xl to rounded-3xl borders (`border-slate-800`).
- **Material Accent Colors:**
  - **Live / Active Accent:** Bright Emerald (`emerald-500` / `#10B981`)
  - **Interaction Accent:** Electric Purple/Indigo (`#6366F1`) or Electric Blue (`#3B82F6`) for active navigation indicators.
  - **Unselected Items:** Dimmed Slate (`text-slate-400` / `hover:text-white`)

#### App-like Micro-Animations
- **Ripple Effect:** Hover/Active states on buttons and navigation items feature scaling animation and soft opacity pulses.
- **Glowing Status Indicator:** A live status badge with custom pulse animations (`.live-glow`) representing continuous streams.
- **Bottom Sheet Transition:** CSS transitions for sliding sheets up from the bottom of the screen (`transition-transform duration-300 ease-out`).

## 6. Authentication System

1. `public/index.php` starts the session, verifies database connection & checks if the site is installed.
2. If `?page=admin&action=login` → shows the login page. On POST, validates admin credentials.
3. Unauthenticated requests to dashboard pages (`?page=admin&...`) are redirected to the admin login.
4. On login, session variables are populated.
5. Logout destroys session variables and redirects.

## 11. UI Component Summary (Android UI Implementation)

The interface is enclosed inside a center-focused column wrapper (`max-w-md mx-auto min-h-screen shadow-2xl relative bg-[#0F1322] pb-20`) to look exactly like a smartphone screen on desktop displays, and fits 100% width on mobile browsers.

### 1. Top App Bar (`views/frontend/header.php`)
- Flat navigation bar (`h-14 bg-[#090D16] flex items-center justify-between px-4 sticky top-0 z-40 border-b border-slate-900`).
- Left: Profile icon/drawer trigger button (`fa-solid fa-bars-staggered`).
- Center: App brand title with glowing icon (`KoraStream` in Outfit font).
- Right: Search button + Telegram shortcut icon (`fa-brands fa-telegram text-sky-400 text-lg`).

### 2. Bottom Navigation Bar (`views/frontend/footer.php`)
- A fixed bottom bar simulating Android navigation (`fixed bottom-0 left-0 right-0 max-w-md mx-auto h-16 bg-[#090D16]/95 backdrop-blur-md border-t border-slate-900 flex justify-around items-center z-50 px-2`).
- Navigation tabs featuring an active indicator pill (Material You style):
  - **Home:** Icon (`fa-solid fa-gamepad` or `fa-solid fa-futbol`), active label.
  - **Channels:** Icon (`fa-solid fa-tv`), label.
  - **Leagues:** Icon (`fa-solid fa-trophy`), label.
  - **Settings:** Icon (`fa-solid fa-circle-info`), label.
- Active tab displays a rounded pill behind the icon (`bg-indigo-600/30 text-indigo-400 px-4 py-1.5 rounded-full transition-all duration-300`).

### 3. Homepage Sliding Tabs (`views/frontend/home.php`)
- **Days Carousel:** Horizontal scrolling slider (`flex space-x-2 overflow-x-auto px-4 py-3 no-scrollbar bg-[#090D16]/40`).
- Days pills: "Yesterday", "Today" (Active, glowing borders), "Tomorrow", followed by direct calendar selector.
- **Match Grid:** Matches are laid out in custom Material cards with:
  - Header: Tournament title & logo, match commentator, and start time.
  - Body: Flex-row with Home Team Logo/Name, VS separator (displaying live time/scores), and Away Team Logo/Name.
  - Footer: Small badge mentioning the broadcasting channel.

### 4. Watch Screen & Server Bottom Sheet (`views/frontend/watch.php`)
- **Video Player Canvas:** Clean container with aspect ratio `aspect-video bg-black relative border-b border-slate-900`.
- Includes Hls.js initialization scripts to parse live streams natively.
- **"Select Server" Floating Trigger:** Styled like a floating Material action button or bottom drawer trigger.
- **Android Bottom Sheet Component:**
  - A hidden drawer (`fixed inset-x-0 bottom-0 max-w-md mx-auto bg-[#181E31] rounded-t-3xl border-t border-slate-800 z-50 transform translate-y-full transition-transform duration-300 ease-in-out`).
  - Features a grey grab handle at the top (`w-12 h-1 bg-slate-700 rounded-full mx-auto my-3`).
  - Lists streaming servers as clean selectable list items (`flex items-center space-x-3 p-4 hover:bg-slate-800 rounded-xl border border-slate-800/40 mb-2 cursor-pointer`).
